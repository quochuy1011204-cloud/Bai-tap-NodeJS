# BÀI 3 - BÀI TẬP 01 NODE.JS

## 1. Mục tiêu
Xây dựng chương trình quản lý danh sách sinh viên bằng Node.js.

## 2. Yêu cầu thực hiện
- Khai báo danh sách gồm 5 sinh viên.
- Mỗi sinh viên gồm mã, họ tên, tuổi và điểm.
- Sử dụng class và constructor để biểu diễn sinh viên.
- Sử dụng arrow function để lọc sinh viên có điểm từ 5 trở lên.
- Sử dụng console.log() để hiển thị danh sách sinh viên đạt yêu cầu.

## 3. Cách chạy tập tin bai01.js

**Bước 1:** Mở thư mục Bt01 bằng Visual Studio Code.

**Bước 2:** Mở Terminal trong VS Code.

**Bước 3:** Nhập lệnh:

```powershell
node.exe bai01.js
```
