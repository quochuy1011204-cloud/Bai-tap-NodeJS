# BÀI TẬP NODE.JS - HTTP SERVER

## 1. Mục đích
Tạo ứng dụng Node.js sử dụng module `http` để xây dựng máy chủ web.

## 2. Yêu cầu thực hiện
- Sử dụng module `http` có sẵn trong Node.js.
- Khởi tạo HTTP Server chạy tại cổng `8080`.
- Khi truy cập trang chủ, hiển thị nội dung HTML gồm họ tên và mã sinh viên.

## 3. Cách chạy chương trình

**Bước 1:** Mở thư mục bài tập bằng Visual Studio Code.

**Bước 2:** Mở Terminal trong VS Code.

**Bước 3:** Nhập lệnh:

```powershell
cd .\BaiTapNodeJS_CuaToi
```

**Bước 4:** Chạy chương trình:

```powershell
node.exe server.js
```

**Bước 5:** Mở trình duyệt và truy cập:

[http://localhost:8080](http://localhost:8080)

## 4. Kết quả
Trang web hiển thị họ tên và mã sinh viên.

## 5. Kết luận
Đã tạo và chạy ứng dụng HTTP Server bằng Node.js, sử dụng module `http` và cổng `8080`.
