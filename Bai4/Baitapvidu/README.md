# Bài 4 – Xây dựng Web với Express

## 1. Giới thiệu
Bài thực hành làm quen với framework Express trong Node.js, thực hành tạo server, định tuyến (Route), Middleware, Template Engine và xử lý lỗi.

## 2. Công nghệ sử dụng
- Node.js
- Express
- Pug
- Handlebars

- http://localhost:3000/calculator

## 4. Cách chạy chương trình

Di chuyển đến thư mục bài tập:

```cmd
cd /d C:\CD-CNTT18A\Bai4
```

Cài đặt thư viện:

```cmd
npm install
```

Chạy file thực hành cần xem:

```cmd
node express.js
```
